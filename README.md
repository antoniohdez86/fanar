
# 🏔️ FANAR

Proyecto escolar realizado en el 2012 para un compañero que al final no se entregó ni se terminó, consta modulos Usuarios, Empleados, Municipios, Nucleos Agrarios, Seguimientos, Reporte.

## 📖 Objetivo
Este proyecto lo tenía en un disco duro arrumbado y lo pongo aqui en este repositorio con **fines educativos**, no está terminado, le falta mucho, está llena de bugs.



## 📦 Tecnologías utilizadas
- [HTML](https://developer.mozilla.org/es/docs/Web/HTML)
- [CSS](https://developer.mozilla.org/es/docs/Web/CSS)
- [Javascript](https://developer.mozilla.org/es/docs/Web/JavaScript)
- [jQuery1.7](https://api.jquery.com/category/version/1.7)
- [PHP](https://www.php.net)
<!-- - CSS3 (opcional: TailwindCSS) -->

## ⚙️ Instalación / Uso
1. Clona este repositorio:
   ```bash
   git clone https://github.com/antoniohdez86/fanar.git
   ```

2. Entra a la carpeta:
   ```bash
   cd fanar
   ```

3. Crear base de datos en servidor mysql con el nombre bd_procedeweb `(por ahora está harcodeado en codigo)` e importar estructura y datos desde el archivo `bd_procedeweb_ultim.sql`

4. Correr el proyecto en un servidor web que soporte php
    - En este caso se usó la opcion de correr el proyecto con la herramienta `Run and Debug > Launch Built-in Web server` de vscode

## ⚠️ ¡AVISO! ⚠️

**Es posible que al intentar correr al proyecto no funcione** dado que este primer commit es la version original del proyecto a como venía en el disco duro desde el 2012, y a modo de practica se irán haciendo correcciones y ajustes de vez en cuando.
